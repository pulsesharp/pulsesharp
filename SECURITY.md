# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub instead: go to the **Security** tab of this repository and choose **Report a vulnerability**.

You will get a reply within 7 days. Once a fix is released, the report is published with credit to you, unless you prefer not to be named.

## Supported versions

PulseSharp is in early development (`0.x`). Only the latest release receives fixes.
