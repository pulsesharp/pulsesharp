# Code of conduct

PulseSharp is open to everyone. We want this project to be a friendly place, whatever your experience, background or country.

## Expected

- Be kind and patient, especially with newcomers.
- Discuss ideas, not people.
- Accept that maintainers decide on the project's direction.

## Not accepted

- Harassment, insults or personal attacks.
- Discriminatory language or jokes.
- Publishing other people's private information.

## Enforcement

Maintainers may edit or remove comments, close issues, or block people who break these rules.

To report a problem privately, use the repository's **Security** tab → **Report a vulnerability**, and start the title with "Conduct:".

This code is based on the ideas of the [Contributor Covenant](https://www.contributor-covenant.org/).
